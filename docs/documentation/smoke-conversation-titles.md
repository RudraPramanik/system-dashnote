# Conversation auto-title — manual smoke

After backend + frontend are running:

1. Open Chat → New → send a real first message (not a blank thread).
2. Confirm the sidebar label becomes a short title (not "New conversation").
3. Open Agent → New session → send a first message.
4. Confirm the session list shows a real title (not "New session").
5. Open an older thread that still shows "New conversation" / "New session" and send another message — title must stay the placeholder (no backfill).
6. Use the ✎ rename control; confirm the new name sticks after refresh.
